# 🚀 Angular Digital Budget App

Aplicación web moderna desarrollada en **Angular** (utilizando señales, control de flujo nativo y componentes modulares) diseñada para la gestión, configuración y cálculo de presupuestos digitales de servicios web, SEO y campañas de publicidad.
![alt text](image.png)
---

## ✨ Características Principales

* **Configurador de Servicios:** Selección dinámica de servicios con precios actualizados en tiempo real y opciones avanzadas de personalización (número de páginas y idiomas para webs, etc.).
* **Gestión de Presupuestos Guardados:** Listado de clientes con presupuestos guardados, incluyendo sus datos de contacto y un **buscador instantáneo** filtrado por nombre.
* **Formulario de Registro:** Captura de datos de contacto del cliente (`#miFormulario`) con validaciones y limpieza automática tras el envío exitoso.
* **Diseño Estricto Mobile First:** Arquitectura CSS estructurada desde cero para dispositivos móviles con saltos adaptativos mediante `@media (min-width: 768px)` tanto en estilos globales como en componentes hijos.

---

## 🛠️ Tecnologías Utilizadas

* **Angular** (versión moderna con Signals y Control Flow)
* **TypeScript**
* **HTML5 / CSS3** (Mobile First, Flexbox)
* **Git & GitHub** para control de versiones
